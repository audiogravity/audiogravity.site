Answers to the questions audiophiles ask about Raspberry Pi and Linux streamers — DACs, libraries,
streaming, Roon, HQPlayer, DSD — checked and dated.

- [AirPlay to a Raspberry Pi: what quality actually arrives](airplay-raspberry-pi-quality.md) — What an iPhone, iPad or Mac really sends to a Pi over AirPlay and AirPlay 2, what Debian's shairport-sync receives, and what it does to the sound.
