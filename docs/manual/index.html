Audiogravity — User Manual

Describes Audiogravity v0.9.33

Welcome to Audiogravity — the conductor of your music streamer. This manual walks you from a bare Linux box to a fully-tuned, browser-controlled hi-fi system.

In a hurry? The Quick start takes you from a bare box to music on one page.

New here? Read 1. Introduction first, then follow 2. Installation and 3. First run in order. Everything else is reference — dip in as you need it.

Read it in the app. The Manual tab (at the end of the tab bar) opens this manual inside Audiogravity itself — a chapter list on the side, the page beside it, always showing the latest published version.
