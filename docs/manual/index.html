Audiogravity — User Manual

Describes Audiogravity v1.0.0-rc.2

Welcome to Audiogravity — the conductor of your music streamer. This manual walks you from a bare Linux box to a fully-tuned hi-fi system, controlled from your browser or your phone.

In a hurry? The Quick start takes you from a bare box to music on one page.

New here? Read 1. Introduction first, then follow 2. Installation and 3. First run in order. Everything else is reference — dip in as you need it.

Read it in the app. The Manual tab (at the end of the tab bar) opens this manual inside Audiogravity itself — a chapter list on the side, the page beside it. It is the manual of the version your box runs, and it opens without internet access; the latest edition is on audiogravity.app.

Contents

  1. Quick start — from zero to music, on one page
  2. Introduction — what Audiogravity is (and isn't)
  3. Installation — get it running on your streamer
  4. First run — guided audio setup: DAC, library, services
  5. Listening — sources, transport, the Now Playing screen
  6. Library & streaming — Qobuz, Tidal, HIGHRESAUDIO, radio, UPnP servers
  7. Outputs & engines — local DAC, network renderers, HQPlayer, AirPlay
  8. Administration — users, services, config editor, performance tuning
  9. Updating — one-click self-update, backup & restore
  10. Troubleshooting — common issues, logs, FAQ
  11. Glossary — the audiophile and UPnP vocabulary, in two lines each
  12. FAQ — quick answers: trial, licence, subscriptions, phone install, updating
